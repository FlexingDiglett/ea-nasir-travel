# Ea-Nasir Travel Booking System

A full-stack PHP flight booking application featuring live API integration, MongoDB caching, and a responsive Bootstrap 5 interface.

## 📂 Project Structure

* **`/classes`** - Contains the core Object-Oriented PHP logic (`Booking.php`, `User.php`, `FlightAPI.php`).
* **`/includes`** - Global files required across the app (Header, Footer, Database connection).
* **`/lang`** - Translation arrays for the multi-language UI (English, Spanish, Italian, German).
* **`/ajax`** - Lightweight endpoint scripts for async JavaScript calls (like the airport auto-complete).
* **`/css`** - Custom stylesheets complementing the Bootstrap 5 framework.
